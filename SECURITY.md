# Security Policy

## Reporting
Please open a private security advisory or contact the maintainer directly for vulnerabilities.

## Supported Versions
Only the `main` branch is supported. This is a research/paper-trading project.

## Key Commitments
- No live trading or fund movement code.
- Secrets never committed.
- CI security gates enforced.
- Human review required for merges.

See [docs/security-architecture.md](docs/security-architecture.md) for the full architecture.
